NAT:
静态1对1公网ip，基本不用
方式一：接口视图下配置静态NAT
[Huawei-GigabitEtherneto/o/o] nat static global { global-address} inside {host-address}
eg:
[port]nat static global 100.1.1.3 inside 10.0.10.1
[port]nat static global 100.1.1.4 inside 10.0.20.1
方式二：系统视图下配置静态NAT
[Huawei] nat static global { global-address) inside {host-address
[Huawei-GigabitEtherneto/o/O] nat static enable

easy ip:
dis nat session all
nat server:
[port]nat server protocol TCP global 100.1.1.3/current-interface(不能.2) 10000(外部不用80，易受攻击) inside 10.0.10.1 www
dis nat server
